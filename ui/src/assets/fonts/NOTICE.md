# TwemojiCountryFlags.woff2

Country flag glyphs, so flags render on Windows, where the system emoji font draws two letters instead.
A subset of "Twemoji Mozilla" made by TalkJS (https://github.com/talkjs/country-flag-emoji-polyfill, MIT).
